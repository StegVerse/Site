# ERL / StegSocials capability note

StegSocials standard capability includes ERL-assisted post preparation: selecting ERL evidence, preparing platform-shaped drafts, preserving provenance, and writing user-controlled draft bundles to platform-specific posting directories for manual publication.

Automated external social-account actions are a separate premium capability. Premium automation may add authenticated connectors, scheduling, publication, retries, confirmation, URL capture, and publication receipts. Preparing a post does not require premium automation.

See `docs/ERL_STEGSOCIALS_POST_PREPARATION_CONTRACT.md` for the provider-neutral contract.
